# Easy Eats

Easy Eats is a plain HTML, CSS, and JavaScript recipe book for anyone who wants to cook affordably, waste less, and learn kitchen skills. It is designed for GitHub Pages and runs without a backend or build step.

## Features

- Weekly recipe cards with dietary filters and 1–5 person household scaling
- Recipe details, ingredients, steps, and ratings saved in localStorage
- Two-week grocery planning for sample budgets and three sample Canadian stores
- Combined grocery lists, pantry exclusions, store comparison, deals, and copy-to-clipboard
- A dedicated My Pantry tab with common presets and custom items users can type and remove
- GreenLeaf, HarbourFoods, BudgetBasket, MegaGrocer, and BulkClub store options
- Nearby store search links using a city/postal code or the browser's location permission
- Ingredient swap chat with more than 25 common substitutions and allergy notes
- Six cooking lessons with a persistent skills tracker
- Responsive warm-green and tomato-red interface for phones and laptops
- Beginner-friendly recipe steps with heat, time, appliances, and required tools
- Saved recipes, refreshable weekly meals, and single-meal swapping
- A My Kitchen appliance setup that adapts recipes to available equipment
- Metric/imperial measurement switching with a location-based default

## View the project

Open `index.html` directly in a modern browser, or publish the repository with GitHub Pages:

1. Push these files to your repository's default branch.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.
4. Use the GitHub Pages URL shown in Settings.

No installation or build command is required.

## Files

- `index.html` contains the page structure and navigation.
- `style.css` contains all responsive styling.
- `data.js` contains the recipes, stores, deals, pantry items, swaps, and skills.
- `app.js` contains the browser interactions and localStorage saving.

Store prices, grocery deals, and all app content are sample demo data.
